# Public pretrained baseline

`face_landmarker.task` is Google's public Face Landmarker float16 version 1,
not captured user data. Run `./setup.sh` from the project root, or run
`.venv/bin/python scripts/download_model.py` from the project root, to fetch it.
The binary is excluded from version control.

- Source: https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task
- Size: 3,758,596 bytes
- SHA-256: `64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff`

Startup checks the pinned checksum offline and never downloads missing assets.
